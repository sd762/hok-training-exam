# 0002: Vite + React + TypeScript 取代 CDN 版 React

## 狀態
已接受

## 背景
參考專案 `sd762/-` 用單一 `index.html`，透過 CDN 引入 React 18，並用瀏覽器內的 Babel standalone 即時轉譯 JSX，完全不需要建置流程。這種做法對小工具很省事，但該專案的 repo 裡留下大量 `fix_*.py`、`fix_*.ps1` 這類臨時修補腳本，顯示出「邊跑邊修」的開發模式——沒有型別檢查、沒有模組化，程式碼變大後難以維護。

本系統（教育訓練測考系統2代）的功能範圍明顯更大：多語言題庫、多角色權限、測驗指派與作答、分析報表、到期通知排程等，預期程式碼量會遠超過清福專案。

## 決策
改用 Vite + React + TypeScript 建置，最終產出一樣是純靜態檔案，一樣部署到 GitHub Pages，只是開發階段多了一次建置流程。

## 後果
- 換得型別安全、模組拆分、開發時熱重載，長期維護成本較低
- 需要 Node.js 開發環境與一次性建置流程設定（GitHub Actions 需自動跑 build 再部署到 Pages，而非直接部署原始檔案）
- 與參考專案的程式碼風格不同，無法直接複製貼上参考專案的元件，需要重新設計元件結構
