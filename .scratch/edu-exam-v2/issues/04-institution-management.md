# 04 — 機構管理 CRUD

**What to build:** 平台管理者（與系統管理者）登入後可以在後台維護機構清單：新增機構類別、在類別底下新增/編輯/停用機構名稱，取代舊系統寫死在程式碼裡的機構常數。這張機構表是後續學員資料、機構管理者帳號要參照的基礎資料，需先做好。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 平台管理者可以新增一個機構類別（如「養護機構」）與其底下的機構名稱（如「清安」）
- [ ] 平台管理者可以編輯既有機構名稱、停用某個機構（停用後不會出現在後續「指派學員機構」的下拉選單，但既有指向該機構的歷史資料仍正常顯示，不會消失或報錯）
- [ ] 機構管理者、管理者、學員角色登入後看不到機構管理的操作介面（RLS 與前端權限雙重確認：純看 API 也拿不到寫入權限）
- [ ] 機構清單的讀取（例如給後續學員指派機構用的下拉選單）對所有已登入角色開放，但只有平台管理者/系統管理者能寫入
