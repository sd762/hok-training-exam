# 05 — 學員管理 + Excel 批次匯入

**What to build:** 平台管理者可以查看/新增/編輯學員資料（工號、姓名、語言別、到職日、目前受訓階段、機構、部門），也可以透過上傳 Excel 批次匯入大量學員。已離職學員只能停用不能刪除（避免誤刪在職人員的歷史紀錄關聯）。

**Blocked by:** 04

**Status:** ready-for-agent

- [x] 平台管理者可以手動新增/編輯單一學員資料，機構欄位從工單 04 建好的機構清單中選擇（使用者實測通過）
- [x] 平台管理者上傳一份符合欄位規範的 Excel 檔案後，多筆學員資料被正確建立，工號重複的資料以「已存在就更新」處理（而非產生重複學員）（Edge Function `bulk_import` 邏輯已實作，走與單筆新增相同的 upsert 路徑）
- [x] 停用（離職）學員後，該學員無法登入，但其歷史作答紀錄與帳號本身不會被刪除（使用者實測：停用/啟用皆正常）
- [x] 已停用的學員可以被刪除；在職學員無法被刪除（只能停用）（使用者實測通過，含原生確認對話框）
- [x] 新建立的學員帳號依 03 的登入機制，可用工號成功登入（帳號建立邏輯與工單 03 共用同一套 account_code→email 轉換）

## UI 改版（2026-07-26，使用者反饋介面太混亂）

原本全部學員平鋪在同一張表，機構一多會很難找人。改成依「機構類別→機構」分成可展開/收合的資料夾（`InstitutionFolder` 元件），標題列顯示該機構人數，預設收合，點擊展開才載入看到學員表格。另外把「國籍」欄位的顯示文字從語言名稱（繁體中文/越南文/印尼文）改成國籍名稱（台籍/越南籍/印尼籍），跟工單 12 報表那邊的用詞邏輯一致。尚未經使用者實際點擊展開/收合操作測試。
