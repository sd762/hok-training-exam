# 05 — 學員管理 + Excel 批次匯入

**What to build:** 平台管理者可以查看/新增/編輯學員資料（工號、姓名、語言別、到職日、目前受訓階段、機構、部門），也可以透過上傳 Excel 批次匯入大量學員。已離職學員只能停用不能刪除（避免誤刪在職人員的歷史紀錄關聯）。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 平台管理者可以手動新增/編輯單一學員資料，機構欄位從工單 04 建好的機構清單中選擇
- [ ] 平台管理者上傳一份符合欄位規範的 Excel 檔案後，多筆學員資料被正確建立，工號重複的資料以「已存在就更新」處理（而非產生重複學員）
- [ ] 停用（離職）學員後，該學員無法登入，但其歷史作答紀錄與帳號本身不會被刪除
- [ ] 已停用的學員可以被刪除；在職學員無法被刪除（只能停用）
- [ ] 新建立的學員帳號依 03 的登入機制，可用工號成功登入
