# 09 — 鏡頭監考整合

**What to build:** 在學員測驗流程中加入鏡頭監考：開考前顯示同意書（明確告知全程無預警擷取鏡頭畫面，需同意才能開始，支援多語言文案），開考後持續開啟鏡頭（含手機前鏡頭）並在前端執行人臉偵測，定期擷取快照上傳至 Supabase Storage 與該次作答綁定。人臉連續3秒未偵測到時，畫面顯示警示要求學員回到鏡頭前（不中止測驗），並記錄一筆「疑似違規事件」供後續審查使用。

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] 開考前顯示鏡頭監考同意書，學員必須明確同意才能進入測驗畫面；不同意則無法開始測驗（並提供清楚說明為何無法開始）
- [ ] 測驗畫面中鏡頭持續開啟，用手機（前鏡頭）與電腦（一般webcam）都能正常啟動
- [ ] 人臉在畫面中消失超過3秒，畫面出現提醒警示，但測驗不會被強制中止、作答不受影響
- [ ] 每次「疑似違規事件」都會記錄時間戳記與對應快照，並與該次作答的紀錄關聯
- [ ] 監考快照儲存在 Supabase Storage，且透過 RLS 確保只有平台管理者（與系統管理者）能夠讀取，其他角色無法直接存取快照網址
