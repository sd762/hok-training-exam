# 09 — 鏡頭監考整合

**What to build:** 在學員測驗流程中加入鏡頭監考：開考前顯示同意書（明確告知全程無預警擷取鏡頭畫面，需同意才能開始，支援多語言文案），開考後持續開啟鏡頭（含手機前鏡頭）並在前端執行人臉偵測，定期擷取快照上傳至 Supabase Storage 與該次作答綁定。人臉連續3秒未偵測到時，畫面顯示警示，累積達門檻自動中止（見 ADR 0005 2026-07-25 修訂：3次警告後中止、計入一次失敗）。額外加入切換視窗/離開頁面偵測（2次即中止，門檻比人臉偵測更嚴格）。

## 實測紀錄（2026-07-25）

使用者實測鏡頭啟動、人臉消失警示、連續3次中止皆正常運作。過程中發生一次 React 崩潰（`insertBefore` DOM 錯誤，已加上 ErrorBoundary 防止再次變成空白畫面），重試後確認整體流程正常，推測是偶發的瀏覽器翻譯功能衝突（React 應用程式與瀏覽器自動翻譯功能的已知相容性問題），非程式邏輯本身的錯誤——**如果之後又重現，需要向使用者確認當下瀏覽器是否有開自動翻譯**。

## 已知範圍限制

只做「有沒有人臉」的存在偵測，不做「是不是本人」的身分比對（見 ADR 0005 說明）。手機實測（前鏡頭啟動、畫面遮擋、切換視窗偵測在行動裝置上的行為）尚未進行。
