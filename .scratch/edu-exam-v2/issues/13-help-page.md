# 13 — 系統內使用說明頁（2026-07-26 使用者需求，原12張工單之外新增）

**What to build:** 在系統裡加一個「使用說明」頁面，讓每個角色登入後都能找到自己那部分功能怎麼用，不用另外看文件或問人。

**Blocked by:** 無特定依賴，但內容涵蓋了工單 01～12 全部功能，實質上要等這些都做得差不多才有東西可寫。

**Status:** done

- [x] 導覽列新增「使用說明」項目，所有角色都看得到（唯一一個不受 `canWrite`/`canViewReports` 限制的導覽項目）
- [x] 內容依角色只顯示相關段落（`src/pages/HelpPage.tsx`，用 `<details>` 折疊、role 判斷用既有的 `canWrite`/`canViewReports`/`role==='super_admin'`）：
  - 帳號與登入（全部角色）
  - 學員應考流程（學員預設展開；其他角色收合，供協助排除問題參考）
  - 學員管理／機構管理／題庫管理（含音訊題/圖片題規則）／管理者帳號／及格審查／通知設定／分析報表（`canWrite`/`canViewReports` 角色可見）
- [x] 內容只寫實際存在的功能，沒有虛構「自行修改密碼」等系統目前沒有的功能——目前密碼只能由管理者重設回預設值 000000，這是實測後刻意寫進說明的已知限制，不是遺漏
