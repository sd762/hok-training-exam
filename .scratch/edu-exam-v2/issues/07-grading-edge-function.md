# 07 — 出題與評分 Edge Function（抽題輪替 + 答案鎖定）

**What to build:** 一支 Supabase Edge Function，負責出題快照（只含題目與選項，絕不含正確答案）與評分（比對正解、計算分數、寫回資料庫）。實作同一鎖定循環（3次/輪）內的抽題輪替規則：第1次全題庫隨機抽25題、第2次從扣除第1次抽過的題目後剩餘題目中抽25題、第3次重新全題庫隨機抽25題。題目顯示順序與選項順序各自獨立打亂，正確答案位置鎖定在資料庫的原始選項順序上，透過每次作答產生的對照表換算顯示位置與原始位置。

**Blocked by:** 05, 06

**Status:** ready-for-agent

- [ ] 呼叫「開始測驗」時，回傳的題目資料不含任何形式的正確答案欄位或可推算出正解的資訊（用網路請求檢視也看不到）
- [ ] 同一位測試學員在同一輪鎖定循環內連續測驗 3 次，第1次與第2次抽出的25題完全不重疊（題庫剛好50題時），第3次則是重新隨機、可能與前兩次重疊
- [ ] 抽出的題目顯示順序，與該題庫在資料庫中的建立順序/ID順序不同（每次重新隨機排列）
- [ ] 提交作答後，Edge Function 正確計算分數（每題4分，滿分100），80分（或該測驗科目設定的及格分數）以上判定及格
- [ ] 連續3次未通過後，第4次嘗試呼叫「開始測驗」會被擋下，回應訊息包含解鎖時間
- [ ] 選項順序打亂後提交答案，評分結果與「選項未打亂時提交同一組邏辑正確的答案」得到相同分數（驗證對照表雙向轉換沒有算錯）
