# 08 — 學員測驗前端流程（不含監考）

**What to build:** 學員登入後看到自己目前受訓階段的應考提醒，可以開始測驗、依序作答25題（不論題型是單選或複選）、提交後看到分數與及格/不及格結果，以及重考次數/鎖定狀態的清楚顯示。多語言介面（繁中/越南文/印尼文）涵蓋整個作答流程與訊息文字。此工單先不包含鏡頭監考（見工單09）。

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] 學員登入後首頁明顯顯示「目前應考測驗」提醒（若有應考義務）
- [ ] 學員可以開始測驗、看到25題依序作答（含單選/複選題型），選項順序是打亂後的顯示順序
- [ ] 提交後立即看到分數、及格與否，以及若不及格時的剩餘次數/鎖定資訊
- [ ] 學員切換到越南文/印尼文語言別後，整個作答流程（包含按鈕文字、錯誤訊息、結果頁面）都顯示對應語言，不會出現「介面翻譯了但題目/訊息還是中文」的混雜情況
- [ ] 作答到一半重新整理頁面或關閉瀏覽器再重新登入，可以續答同一次未完成的測驗（而非強制重新開始）
