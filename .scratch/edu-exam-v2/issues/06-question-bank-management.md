# 06 — 題庫管理(多語言) + Excel 匯入/翻譯範本

**What to build:** 平台管理者可以管理各受訓階段的題庫：一題多語言（繁體中文必填，越南文/印尼文選填），選項數量與順序三語言保持一致。支援用 Excel 批次建立繁體中文題目，並可下載「翻譯範本」（帶入現有中文題目供對照）填好翻譯後上傳補齊。各語言題目數量不需要一致（中文題庫本來就會比外語題庫多）。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 平台管理者可以手動新增一題，含繁體中文內容（必填）與越南文/印尼文翻譯（選填），正確答案的位置記錄在語言中立的「原始選項順序」上（呼應之後評分要用的答案鎖定機制）
- [ ] 平台管理者可以用 Excel 批次建立整批繁體中文題目
- [ ] 平台管理者可以下載某個受訓階段的「翻譯範本」（自動帶入現有中文題目與選項供對照），填好越南文或印尼文翻譯後上傳，對應題目補上該語言翻譯
- [ ] 某語言翻譯題數比中文少，系統不會因此擋下該語言的題庫管理操作或跳出錯誤（只要求最終抽題時該語言可用題數達到門檻，門檻判斷邏輯在工單 07）
- [ ] 停用某一題後，該題不會出現在後續的隨機抽題結果中，但既有考試紀錄中的歷史快照不受影響
