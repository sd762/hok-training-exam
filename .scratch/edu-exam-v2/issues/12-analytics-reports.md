# 12 — 分析報表（Postgres RPC + 前端圖表）

**What to build:** 四類分析報表（學員分析／考題分析／考測結果分析／人力留任分析），彙總運算寫成 Postgres 資料庫函式（RPC）或 View，前端只取彙總結果來畫圖表。支援時間軸主篩選（年度/半年/季）＋機構/國籍等次篩選。三種「可看全機構」的角色（系統管理者/平台管理者/管理者）看得到全部資料；機構管理者只看得到自己機構的數據，且此限制由 RLS 在資料庫層強制。

**Blocked by:** 08, 10

**Status:** ready-for-agent

- [ ] 四類報表都能正確顯示，數據與資料庫中的實際作答紀錄一致
- [ ] 時間軸篩選（年度/半年/季）與機構/國籍等次篩選可以組合使用，篩選後數據正確變動
- [ ] 機構管理者登入後看到的報表只涵蓋自己機構的學員，且直接呼叫報表 API 帶入其他機構的參數也拿不到資料（RLS 擋下，非只靠前端隱藏）
- [ ] 「管理者」角色可以查看所有機構的報表，但介面上沒有任何新增/修改/匯入/審查的操作入口，且直接呼叫寫入 API 會被 RLS 拒絕
- [ ] 報表在資料量增長後仍能正常載入（彙總在資料庫端完成，不是把明細整批下載到瀏覽器再算）
- [ ] 只有「已確認通過」的作答會被計入及格率等正式統計數字，「待核對」與「存疑保留」狀態需明確區分顯示，不會被誤算為已通過
