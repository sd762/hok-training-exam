# 10 — 及格審查流程（平台管理者）

**What to build:** 學員及格後，作答狀態進入「待核對」，通知平台管理者。平台管理者可以在一個審查佇列裡看到所有待核對的及格作答，點開查看監考證據（快照、疑似違規事件），確認「核對無誤」（狀態變「已確認通過」，正式納入及格紀錄，對應監考快照可清除）或標記「存疑保留」（保留證據待進一步調查）。學員在「待核對」或「存疑保留」狀態下不能推進到下一受訓階段，也不會誤觸發下一階段的到期通知。「存疑保留」最終被判定不合格時，視為作廢重新計算，不追溯扣考試機會。

**Blocked by:** 09

**Status:** ready-for-agent

- [ ] 學員及格後，平台管理者能在審查佇列中看到這筆「待核對」的作答，包含學員資訊與該次的監考快照/疑似違規事件
- [ ] 平台管理者標記「核對無誤」後，狀態變為「已確認通過」，該學員的受訓階段可以正確推進到下一階段
- [ ] 平台管理者標記「存疑保留」後，狀態變為「存疑保留」，監考快照與紀錄不會被清除，該學員無法推進到下一階段
- [ ] 機構管理者登入後可以看到自己機構學員的「待核對」/「已確認通過」/「存疑保留」狀態顯示，但沒有任何操作核對的按鈕或權限（含直接呼叫 API 也應被 RLS 擋下）
- [ ] 學員停留在「待核對」或「存疑保留」狀態期間，即使剛好到了下一里程碑的通知窗口，也不會誤發下一階段的到期通知
- [ ] 「存疑保留」最終被標記為不合格後，重新計算的下一次測驗視為新一輪的「第1次」，不計入原本3次鎖定循環的額度
